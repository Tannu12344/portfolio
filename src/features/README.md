# features/

Reserved for future interactive, game-influenced features that go beyond
plain UI components — each will live in its own subfolder here once built:

- `developer-world/` — the larger interactive "world" concept
- `skill-tree/` — interactive skill visualisation
- `project-explorer/` — interactive project browsing experience
- `command-palette/` — keyboard-driven navigation (⌘K style)
- `easter-eggs/` — hidden interactions

Intentionally empty in Phase 1 (Foundation).
